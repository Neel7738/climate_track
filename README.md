# 🌦️ ClimaTrack – Weather Data Analyzer

**ClimaTrack** is a Python-based desktop application that helps you **analyze, visualize, and predict weather patterns** from CSV datasets.  
It combines **Tkinter (for GUI)**, **Seaborn + Matplotlib (for analysis)**, and **Turtle (for fun animations)** to create an engaging weather analytics experience.

---

## 🧩 Features

✅ **Load Weather Data**
- Import weather data from a CSV file containing:
  - `date`
  - `temperature`
  - `rainfall`
  - `humidity`
  - `wind_speed`

✅ **Analyze Statistics**
- Calculate:
  - Average, minimum, and maximum temperature  
  - Total rainfall  
  - Most humid and windiest days  

✅ **Visualize Data**
- Temperature trends over time  
- Rainfall distribution histogram  
- Humidity and wind speed variation plots  
- Correlation heatmap for all weather variables  

✅ **Predict Weather**
- Gives a simple next-day weather prediction based on recent humidity and temperature patterns.  

✅ **Weather Animation**
- Displays a fun turtle-based **rain animation** to simulate rainy weather.  

✅ **User-Friendly GUI**
- Built entirely with Tkinter for easy interaction.
